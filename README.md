## 🗂️ Core Architecture & Multi-Page Routing

Following **"The Anatomy of a Hire-Ready Portfolio"**, this application implements 6 dedicated routes:

* **`/` (Home / Hero Intro)**: 
  * Interactive portrait frame with cyber corner brackets, `FULLSTACK DEV`, and `v. 2026` badges.
  * Real-time availability pill (`AVAILABLE FOR HIRE`).
  * Core value proposition (*"Why first. Code second."*).
  * 3-column stats bar and quick CTAs.
* **`/about` (About Story)**: 
  * Developer narrative, problem-solving mindset, and execution pillars.
* **`/skills` (Tech Stack)**: 
  * Competencies organized into 3 clear categories: Frontend Engineering, Backend & Systems, and Tools/DevOps.
* **`/projects` (Featured Work)**: 
  * In-depth project cards with live demo links, respective GitHub repo buttons, highlights, and browser mockup frames.
* **`/resume` (Resume / CV)**: 
  * Clean, comprehensive CV layout with a built-in one-click **Print / Save as PDF** feature.
* **`/contact` (Contact & Inquiries)**: 
  * Prominent WhatsApp direct chat integration (`+880 1319-448692`), interactive message form, and social profiles.
* **`/not-found`**: Custom 404 page with seamless home redirection.

## 💻 Local Development Setup

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/taseen311/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000).

5. **Type check & Build:**
   ```bash
   npx tsc --noEmit
   npm run build
   ```
